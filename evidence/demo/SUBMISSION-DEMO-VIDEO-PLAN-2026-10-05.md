# Clearance Room — Submission Demo Video Plan

Date: 2026-10-05  
Target: judge-facing submission demo  
Duration: **72 seconds**  
Language: **English**  
Film project: `8a3b6606-5fd8-4963-8944-48b9f2d31cd1`

## Core rule

The video packages the real product. It does not define the product and must never substitute fabricated footage for runtime truth.

Allowed footage:
- real Vercel preview interaction;
- real live Sanity data;
- real deterministic verdicts;
- real source evidence;
- real Content Agent output only after it has actually run;
- real remediation receipts and proof history.

Not allowed:
- generated recreation of the UI;
- invented usage data;
- fake final CLEAR;
- fake timestamps;
- fake agent narration presented as runtime output;
- fake proof receipts.

## Narrative

**Change -> Blast Radius -> Verdict -> Evidence -> Bounded AI -> Safe Action -> Human Approval -> Proof**

## Shot list

### 0–6s — Product thesis
Real Shockwave hero.

Voiceover:
"Rights changes don’t break in isolation. Clearance Room shows what breaks downstream before a change goes live."

### 6–16s — Published vs Proposed
Toggle Published / Proposed on the real Shockwave map.

Voiceover:
"It compares published and proposed rights, then places every live usage on a deterministic blast-radius map. The distance changes because the verdict changes — not because an AI guessed."

### 16–25s — Select the risk
Select the highest-risk real usage and open its case file.

Voiceover:
"Select any impacted usage and you immediately see the status transition, the causal right, and whether a supported action actually exists."

### 25–37s — UNKNOWN case
Show real CLEAR -> UNKNOWN, NOT DOCUMENTED and the deterministic verdict ledger.

Voiceover:
"Here, a missing validity boundary moves this usage from CLEAR to UNKNOWN. Clearance Room refuses to infer permission when the structured rights data is incomplete."

### 37–47s — Evidence + bounded agent
Show real source evidence. Run the real Content Agent if available. Keep decision/write authority badges visible.

Voiceover:
"The governing source is shown separately from the decision. The agent may explain the case, but it has no decision authority and no write authority. On UNKNOWN, it must abstain."

### 47–58s — Repairable case
Open a real BLOCK or REVIEW case with a registry-backed action.

Voiceover:
"For a repairable case, Clearance Room exposes only registry-backed actions. It never promises the result in advance — the final status must be recomputed after the write."

### 58–67s — Human approval + proof
Show explicit approval, real write/recompile, then actual proof chain.

Voiceover:
"A consequential change still requires explicit human approval. After the write, the old proof becomes stale, the graph is reread, and a replacement proof records the recomputed result."

### 67–72s — Close
Return to the product overview.

Voiceover:
"That is Clearance Room: deterministic, evidence-backed rights impact before publication."

On-screen close:
**See what breaks before a rights change goes live.**

## Capture requirements

- 16:9 landscape master.
- Record at a readable desktop viewport; avoid browser chrome where possible.
- Cursor movements should be slow and intentional.
- No speed ramps over text that judges must read.
- Preserve natural UI transitions.
- Use the preview design branch until TRACE passes.
- Capture mobile separately for assurance, not necessarily for the 72-second master.
